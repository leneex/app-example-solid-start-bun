# SolidStart on Bun

Example [SolidStart](https://start.solidjs.com/) app running on [Bun](https://bun.sh/). SolidStart is the full-stack framework for Solid, with routing and server-side rendering. Bun is a fast all-in-one JavaScript runtime and package manager compatible with Node.js.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — Railpack build |
| Single-page application (SPA) | off |
| Project directory | `/` |
| Output directory | `/.output/public` |
| Install command | leave empty |
| Build command | leave empty |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
bun install

# run in development mode
bun run dev

# build for production
bun run build

# preview the built static version
bun run preview
```
